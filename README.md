SPaRK: An IoT System for Proactive Regulation of Key Factors to Electrical Fires

* Built a 3-node IoT fire-risk monitoring system on STM32 MCUs, integrating DHT11 (humidity), LM35 (temperature), and MQ2 (gas) sensors with ESP-01 Wi-Fi modules and local buzzers.
* Developed a cloud-based monitoring dashboard with React.js and ThingSpeak with 3 real-time sensor visualizations and MATLAB-actuated email alerts across 7 distinct alert conditions.
* Uses ESPDataLogger and UARTRingBuffer scripts made by controllerstech.
